# Code Review Skill

## 适用场景
- 用户请求审查某个模块的代码质量
- 需要识别潜在 bug、坏味道、风格问题

## 审查清单
1. **正确性**：边界条件、异常处理、资源释放
2. **可维护性**：函数长度、命名、注释覆盖率
3. **安全性**：输入校验、路径越界、命令注入
4. **性能**：IO 次数、循环复杂度、缓存命中

## 输出格式
用 Markdown 分节列出问题 + 建议 + 严重等级（high/medium/low）。
